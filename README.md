# LeetCode 算法刷题仓库
个人算法学习仓库，Python / C++实现，包含动态规划、滑动窗口、二分、组合数学、数论等题型。

## 仓库目录
- dp：动态规划题目
- sliding_window：滑动窗口、双指针
- binary_search：二分查找
- prefix_sum：前缀和、前缀异或
- math：组合计数、模运算、数论相关题目
- enumeration：枚举、暴力遍历类题目


## 项目说明
- 累计完成LeetCode近300道算法题，覆盖动态规划、滑动窗口、二分查找、枚举、组合计数、数论等题型
- 源码中记录解题思路、边界条件与调试踩坑记录
- 练习时间、空间复杂度分析，归纳各类题型通用解题模板

## 技术栈
